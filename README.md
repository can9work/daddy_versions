# daddy_versions

Latest versions and release notes of the daddy scripts. Each script reads `versions.json` once when the server starts and prints a notice in the console when a newer version is out. Nothing is sent from your server.

| Script | Version | Release notes |
| --- | --- | --- |
| daddy_bills | 0.0.1 | [CHANGELOG](daddy_bills/CHANGELOG.md) |
| daddy_venue | 0.0.1 | [CHANGELOG](daddy_venue/CHANGELOG.md) |
| daddy_hud | 0.0.1 | [CHANGELOG](daddy_hud/CHANGELOG.md) |

Updates are downloaded from the [CFX Portal](https://portal.cfx.re/assets/granted-assets). To turn the check off set `VersionCheck = false` in the config of the script.
